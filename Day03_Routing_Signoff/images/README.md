- `m4_drc_2.png` — second validated M4.S.5 case traced to routed geometry.
- `m4_drc_geometry.png` — DRC-to-route debugging workflow.
- `drc_report.png` — 39-marker DRC summary.
- `final_gds.png` — final implementation/GDS flow and timing results.

These are explanatory visuals rather than fabricated screenshots of OpenROAD/KLayout.
